3 KLAIM YANG DIPAKAI (setelah validator):
--------------------------------------------------------------------
[1] BGN menegaskan kendaraan distribusi bukan komponen biaya operasional MBG.
    → Dari judul: "BGN: Kendaraan Distribusi MBG Tak Masuk Biaya Operasional Rp3.000"
    → Sudut: pihak yang menyatakan + perubahan aturan

[2] Mobil SPPG tidak lagi ditanggung di anggaran operasional MBG.
    → Dari judul: "Biaya Operasional MBG Rp3.000, Mobil SPPG Tak Lagi Ditanggung"
    → Sudut: siapa yang kini menanggung (mitra SPPG)

[3] Rp3.000 per penerima manfaat tidak lagi mencakup kendaraan.
    → Dari judul: "BGN Hapus Biaya Distribusi MBG Rp3.000 Per Penerima: Kami Kembalikan Kebijakan Semestinya"
    → Sudut: pos anggaran + angka + satuan seperti di judul

KLAIM YANG DIBUANG VALIDATOR (dari 5 klaim LLM awal → 3):
--------------------------------------------------------------------
Original 5 LLM claims (sebelum validator):
  1. "BGN menegaskan kendaraan distribusi bukan komponen biaya operasional MBG." → LOLOS
  2. "BGN mengeluarkan kendaraan distribusi dari komponen biaya operasional program MBG." → DUPLIKAT >0.5 mirip #1 (Jaccard)
  3. "BGN menghapus komponen biaya kendaraan dari anggaran operasional MBG." → DUPLIKAT >0.5 mirip #1/#2
  4. "Mobil SPPG tidak lagi ditanggung dalam biaya operasional MBG Rp3.000." → LOLOS (sudah beda: SPPG, ditanggung)
  5. "Rp3.000 per penerima manfaat tidak lagi mencakup kendaraan." → LOLOS (sudah beda: pos anggaran)

Alasan dibuang:
- Klaim 2 & 3: Kemiripan kata isi >0.5 dengan klaim 1 (hanya "BGN ... kendaraan ... biaya operasional MBG")
- Validator _mirip() pakai Jaccard pada _kata_isi() (tanpa stopword, tanpa kata topik generik)

SUDAH ADA DI 3 KLAIM?
--------------------------------------------------------------------
✓ Insentif harian dipangkas → TIDAK ADA (hanya di judul "Insentif Harian Juga Dipangkas", LLM tidak generate klaim terpisah)
✓ Gaji pengawas gizi/keuangan → TIDAK ADA (hanya di judul "BGN Ungkap Nasib Gaji Pengawas", LLM tidak generate)
✓ Alasan resmi "wajib dipenuhi SPPG" → TIDAK ADA (hanya di judul "Karena Wajib Dipenuhi SPPG", LLM tidak generate)

→ Sudut insentif, gaji pengawas, alasan resmi HILANG dari 3 klaim final.
  Karena hanya muncul di 1-2 judul dan LLM tidak mengeksposnya sebagai klaim terpisah.
  System prompt rule 6 minta "jika judul memuat 'karena...' atau dampak ke pos lain, jadikan klaim sendiri" → LLM tidak mematuhi.
